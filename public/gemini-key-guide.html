🔑 구글 제미나이(Gemini) 키 받기 무료

브랜드 네이밍 스튜디오는 이 키 하나로 브랜드 이름을 만들어요. 키가 있어야 시작할 수 있어요.

먼저 알아 두세요

  • 결제는 필요 없어요. 브랜드 네이밍은 무료 키로 충분히 쓸 수 있어요. 카드도, 주민번호도 넣지 않아요.
  • 3분이면 끝나요. 구글 로그인 → 키 복사 → 프로그램에 붙여넣기, 이렇게 세 가지만 하면 돼요.
  • 하루 사용량 한도는 있어요. 수업 중에 여러 번 눌러도 넉넉한 양이에요. 한도를 넘으면 안내가 뜨고, 다음 날 다시 채워져요.
  • 시작하는 방법은 2가지예요. 구글에 로그인돼 있지 않으면 ①부터, 이미 로그인돼 있으면 ②부터 하세요.

① 로그인 안 돼 있을 때 (방법 1)

1. aistudio.google.com → [Get started]

주소창에 aistudio.google.com → 오른쪽 위 [Get started]

2. 구글 이메일 넣고 [다음]

구글 아이디가 없으면 [계정 만들기]로 먼저 만들어요. 휴대폰 번호는 문자 확인용이에요(법인폰 가능).

3. 비밀번호 넣고 [다음]

4. '간편한 로그인' → [나중에]

5. '집 주소 설정' → [건너뛰기]

6. '프로필 사진 추가' → [건너뛰기]

→ 7단계 '환영합니다' 화면으로 이어져요.

💡 4~6단계는 구글이 그때그때 다르게 물어봐요. 안 나오면 그냥 넘어가요.

② 여기서부터 같아요 (이미 로그인돼 있으면 여기서 시작 — 방법 2)

7. '환영합니다' → 첫 번째 칸 체크 → [계속]

만 18세 이상 칸(빨간 *)만 체크하면 돼요. 소식 받기 칸은 선택이에요.

8. '방문 목적' → 왼쪽 아래 [건너뛰기]

9. 왼쪽 아래 🔑(열쇠) 누르기

(또는 왼쪽 메뉴 Dashboard → API 키)

10. 키가 이미 만들어져 있어요 → 키 옆 복사 버튼

처음 가입하면 구글이 키를 자동으로 하나 만들어 줘요. 키 줄 오른쪽의 복사 버튼(□)을 눌러 키를 복사해요. (키가 없으면 오른쪽 위 [API 키 만들기])

⚠️ 파란 [결제 설정] 버튼은 누르지 않아도 돼요. 결제 등급이 '무료 등급'인 채로 그대로 쓰면 됩니다.
⚠️ 키는 비밀번호와 같아요. 메모장에 따로 저장해 두시고, 카톡·단톡방·블로그에는 올리지 마세요.

③ 브랜드 네이밍 스튜디오에 넣기

11. 프로그램을 열고 키 붙여넣기

  1. bland-name-studio.vercel.app 접속
  2. 첫 화면 Gemini API Key 칸에 복사한 키를 붙여넣기 (Ctrl+V / ⌘V)
  3. [시작하기] 누르기
✅ 여기까지 하면 끝이에요. 바로 브랜드 이름을 만들 수 있어요.
키는 이 브라우저에만 저장되고 서버로 보내지 않아요. 다음에 들어올 때는 다시 넣지 않아도 돼요.
💡 키를 바꾸고 싶을 때는 화면 오른쪽 위 [API 키 변경] 버튼을 누르면 돼요.

자주 묻는 질문

  • Q. 정말 무료로 쓸 수 있나요?
    네. 브랜드 네이밍에 쓰는 양은 아주 적어서 무료 사용량으로 충분해요. 결제를 등록하지 않아도 키가 바로 나와요.
  • Q. "구글 AI 서버가 혼잡합니다"라고 떠요.
    구글 쪽에 이용자가 몰릴 때 잠깐 나타나는 현상이에요. 30초~1분 뒤에 [다시 시도]를 눌러 주세요. 프로그램이 다른 경로로도 자동으로 우회해 봅니다.
  • Q. "무료 사용량을 모두 썼다"고 떠요.
    하루 한도를 다 쓴 경우예요. 잠시 뒤에 다시 시도하시거나, 다음 날 이용해 주세요.
  • Q. "결제 크레딧이 모두 소진되었다"고 떠요.
    예전에 결제를 등록해 둔 키를 쓰고 있고 충전 잔액이 0원이 된 경우예요. 잔액이 0이 되어도 자동으로 무료로 내려가지 않아요. 결제가 연결되지 않은 새 프로젝트에서 키를 새로 발급받아 [API 키 변경]에 넣으면 무료로 다시 쓸 수 있어요.
  • Q. 키가 남에게 알려졌어요.
    AI Studio API 키 화면 → 그 키 줄 오른쪽 ⋮ → 삭제 → [API 키 만들기]로 새 키를 받고, 프로그램의 [API 키 변경]에 다시 넣어요.
  • Q. 키를 넣었는데 "API 키가 올바르지 않습니다"라고 나와요.
    앞뒤에 빈칸이나 줄바꿈이 섞여 들어간 경우가 많아요. 키 전체를 다시 복사해서 붙여넣어 주세요. 키는 보통 AIza로 시작해요.
  • Q. 다른 컴퓨터에서도 쓰려면요?
    키는 브라우저에 저장되기 때문에, 다른 컴퓨터에서는 같은 키를 다시 붙여넣으면 돼요. 그래서 키를 메모장에 저장해 두시는 게 좋아요.
📦 (참고) 유료 결제 — 지금은 필요 없어요
브랜드 네이밍만 쓰신다면 이 부분은 건너뛰셔도 됩니다. 한 번에 수백 번씩 돌리는 대량 작업이 필요할 때만 참고하세요.
  • 충전한 돈은 환불되지 않고 1년 뒤 사라져요. 꼭 필요할 때 작게 시작하세요.
  • 주민번호 전체·신분증은 필요 없어요. 카드사 본인 확인 때 앞 7자리만 넣어요.
  • 법인폰·법인카드도 돼요.
  • 시작점은 위 10단계에서 파란 [결제 설정]을 누르는 것부터예요.

11. 국가 '대한민국' → 약관 두 칸 체크 → [동의 및 계속]

맨 아래 '이메일 업데이트' 칸은 선택이에요.

12. 계좌 유형 고르기 — 개인이면 '개인', 사업자면 '회사명'

개인이면 개인, 사업자면 사업자(회사명)로 넣으세요. 세금계산서 등은 이 정보로 나와요.

13. (사업자) 세금 정보 넣기

사업자 유형(일반과세 등) · 사업자등록번호 · 업태 · 업종 · 대표자명 또는 대리인

14. 이름 및 주소 넣기

도/시 · 시/군/구 · 주소 · 업체명 · 이름 · 우편번호 (사업자등록증 주소와 같게 넣으면 돼요)

15. 기본 연락처 확인 → [계속]

담당자 이름은 결제 메일을 받을 사람이면 돼요. 전화번호는 선택이에요.

16. 카드사 본인 확인 → [코드 전송] → 코드 입력

이름 · 주민번호 앞 7자리 · 통신사 · 전화번호. 그 카드에 등록된 사람의 정보로 넣어요.

17. 카드 번호 · 카드 비밀번호 앞 2자리 · 유효기간(MM/YY) → [계속]

18. 크롬이 '카드를 저장할까요?' 물으면 → [나중에]

컴퓨터를 같이 쓰면 저장하지 않는 게 안전해요.

19. 크레딧 구매 — 최소 금액부터 시작, 자동 충전 켜기 → [계속]

처음엔 최소 금액(₩8,000)을 추천해요. 매일 쓸 거면 [자동 충전]을 켜 두세요. 잔액이 0원이 되면 그 순간부터 생성이 멈춰요.

20. '결제 완료' → [완료]

21. '설정 완료' → [완료]

22. 결제 등급이 'Tier 1'로 바뀌었는지 확인 → 키 옆 복사 버튼

'무료 등급' 대신 Tier 1이 보이면 유료가 된 거예요. 키는 처음 받은 그대로 쓰면 돼요.
